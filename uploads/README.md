# uploads

Place uploaded media referenced by `index.html` here, using these exact filenames:

- `72b668d4-6ad0-436f-98dd-f7ba1b8b93ef_edited-db5b53d7.jpg` — the profile photo on the About page (**required**)
- `IMG_5502.jpg` — small thumbnail on the music-player card stack (optional)
- the `.mp3` background-music tracks listed in `index.html`'s player (optional — the player just won't have audio for a track until its file is added)

To add a file here on GitHub: open this folder in your browser, click **Add file → Upload files**, then drag the file in and commit.
