# assets

Place image assets referenced by `index.html` here, using these exact filenames:

- `logo.png` — the "K" logo mark shown in the top nav
- `scherr.png`, `fleet-engagement.jpg`, `fleet-engagement-detail.png`, `aerospace-workshop.jpg`, `bethel-cwm.png`, `the-koop.png`, `wrobe.png` — project thumbnail images (optional; each falls back to a placeholder box if missing)

To add a file here on GitHub: open this folder in your browser, click **Add file → Upload files**, then drag the image in and commit.
